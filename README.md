# SecVMS

Лёгкий десктопный просмотрщик IP-камер и видеорегистраторов для Windows — в духе Smart PSS Lite,
но самодостаточный, на C++17 / Qt6 / FFmpeg, без вендорских SDK.

**Версия: 0.9.0** — рабочий прототип для реального поста видеонаблюдения. Мультивендорный:
опрашивает регистраторы Xiongmai, Dahua и TVT/Uniview по их **родным протоколам**.

> Лицензия MIT. Проект выложен «как есть» — берите, форкайте, дорабатывайте.

## Что уже сделано

**Мультирегистраторность**
- Диспетчер устройств: добавление, редактирование, удаление, импорт/экспорт, таблица
  (№, Имя, IP, Тип, Модель, Порт, Каналы, Статус).
- Каждый открытый регистратор — своя вкладка «Просмотр», единое окно переиспользуется
  (не плодит вкладки).

**Три вендорских протокола (свои клиенты, без чужих DLL)**
- **Xiongmai / Sofia (DVRIP, порт 34567):** логин, список камер `NetWork.RemoteDeviceV3`,
  имена каналов `ChannelTitle`, online/offline `NetWork.ChnStatus`.
- **Dahua (HTTP CGI, порт 37777/80):** `configManager.cgi?...RemoteDevice` + `getCameraState`.
- **TVT / Uniview / Tiandy (LAPI, порт 80):** `System/Security/Login` + `Channels/System/ChannelDetailInfos`,
  HTTP Digest (realm `NVRDVR`). Универсально для ребрендов платформы.

**Опрос состояния — у самого регистратора**
- При открытии просмотра (и при переключении вкладок) — окно загрузки и **один опрос регистратора**:
  реальные имена каналов + какие камеры online/offline. Камеры по отдельности не опрашиваются.
- Офлайн-каналы помечаются «недоступна» и не стримятся.

**Видеостена**
- Раскладки 1 / 4 / 9 / 16 / произвольная (NxM); пагинация каналов.
- Отдельный поток-декодер FFmpeg на камеру; тайминг по PTS (плавность без «моргания»),
  скейл в декодере (экономит CPU), опциональный GPU-декод (D3D11VA) для крупного вида.
- Потоки живут постоянно (не переоткрываются при смене раскладки), авто-переподключение,
  бесшовное переключение основной/суб-поток, двойной клик — камера крупно.

**Автопоиск без логина/пароля**
- ONVIF WS-Discovery (multicast) + Dahua UDP-broadcast + многопроходный зонд портов
  (живость → RTSP OPTIONS → уточнение вендора). Логин/пароль спрашивается только на «Добавить выбранные».

**Диалог добавления**
- Кнопка «Определить» — автоопределение протокола/управляющего порта/модели по IP.
- Все поля обязательны (валидация), Enter → «Добавить», Esc → закрыть, очистка полей при закрытии.

**Прочее**
- Страница настроек (сгруппированная), страница «Запрос журнала» с экспортом в CSV,
  иконка приложения и своя рамка окна, конфиг в `%APPDATA%\SecVMS\SecVMS\config.json`.

## Чего пока нет (roadmap)

- **Воспроизведение архива** с регистратора (кнопка есть — модуль не реализован).
- **PTZ**, снапшот, звук.
- **События/тревоги**: всплытие камеры по детекции движения (события DVR доступны, UI нет).
- **«Режим поста»**: старт в полный экран/киоск, восстановление сессии, скрытие курсора.
- **Шифрование учёток**: сейчас пароли в `config.json` в открытом виде (осознанно, для личного использования).
- Другие вендоры (Hikvision SDK-порт 8000 и т.п.), туры/секвенции раскладок.
- Только Windows (GPU-декод через D3D11VA; сетевой код и Qt — переносимы).

## Сборка (Windows, MSYS2 UCRT64)

Тулчейн — [MSYS2](https://www.msys2.org/), окружение **UCRT64**.

```bash
# в MSYS2 UCRT64 shell
pacman -S --needed \
  mingw-w64-ucrt-x86_64-gcc \
  mingw-w64-ucrt-x86_64-cmake \
  mingw-w64-ucrt-x86_64-ninja \
  mingw-w64-ucrt-x86_64-qt6-base \
  mingw-w64-ucrt-x86_64-qt6-svg \
  mingw-w64-ucrt-x86_64-ffmpeg \
  mingw-w64-ucrt-x86_64-pkgconf

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

### Запуск / раздача
Приложению рядом с `SecVMS.exe` нужны:
- папка **`assets/`** (иконки SVG) — из репозитория;
- DLL Qt6 и FFmpeg + их зависимости, плагин платформы `platforms/qwindows.dll`,
  форматные плагины (`imageformats/`, `iconengines/`), `styles/`, `tls/`, `networkinformation/`.

Замкнуть зависимости можно `ldd build/SecVMS.exe` (в UCRT64) и скопировать все `ucrt64/bin/*.dll`,
на которые он ссылается, плюс каталоги плагинов из `ucrt64/share/qt6/plugins/`.
Конфиг с устройствами (`config.json`) в репозиторий **не входит** — создаётся приложением
в `%APPDATA%` (содержит пароли в открытом виде — не коммитьте его).

## Структура

| Файл | Назначение |
|------|-----------|
| `MainWindow.*` | окна/навигация, диспетчер устройств, автопоиск, опрос регистраторов, настройки, журнал |
| `LiveView.*` | одна вкладка просмотра: дерево, панель, раскладки |
| `VideoWall.*` / `VideoCell.*` | видеостена и ячейка (поток-декодер FFmpeg, отрисовка кадров) |
| `XmClient.*` | клиент Xiongmai/Sofia DVRIP |
| `DahuaUtil.h` | разбор Dahua RemoteDevice |
| `Discovery.*` | ONVIF WS-Discovery + Dahua broadcast |
| `StreamUrl.h` | сборка RTSP-URL по вендору |
| `Types.h` | модели `Device` / `CamRef` |
| `Journal.*` / `Errors.*` | журнал и тексты ошибок |

## Оговорка
Инструмент для личного/служебного использования на СВОЁМ оборудовании. Опрос чужих устройств
без разрешения — незаконен. Пароли в конфиге не шифруются.
